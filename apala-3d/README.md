# Apala chrom – model 3D

Interaktywny model 3D baterii kuchennej Blue Water Apala (chrom), zbudowany parametrycznie w Three.js na podstawie zdjęć produktu. Proporcje są przybliżone.

Otwórz `index.html` w przeglądarce (wymaga internetu – Three.js ładuje się z CDN).

- obrót myszą, zoom kółkiem, widoki Przód/Prawa/Tył/Lewa/Góra
- obrót wylewki o 360°, strumień wody, opcjonalny blat
- eksport do GLB (przycisk „Pobierz GLB”)
